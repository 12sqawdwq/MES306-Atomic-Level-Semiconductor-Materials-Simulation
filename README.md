## 原理深入

每个知识模块按 **课件截图 → 中文解释 → 原理深入 → Ref** 组织：

1. 对照原图理解课件在解决什么问题。
2. 阅读中文说明，确认符号、基底与物理含义。
3. 学习补充推导、适用条件与可手算的验证方法。
4. 沿 Ref 回到原 PDF 页码，或查阅延伸参考资料。

第一周的主线是：**物理模型 → 选择基底 → 构造哈密顿量 → 求本征态与能量 → 计算材料性质**。

截图以 1920 × 1080 PNG 保存，共 84 张，覆盖四份讲义除封面、结束页外的页面。笔记按主题选图，原图中的笔误不做涂改，而在正文和勘误页说明。公式使用 Markdown + LaTeX；可在 GitHub 或支持数学公式的编辑器中阅读。复制笔记时应保留相对目录与截图文件。
